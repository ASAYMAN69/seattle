# SKILLS.md — Picasso (Frontend) skill map

> **How to use this file.** At the start of every task, read this list. Load a skill **only if its trigger condition is true** for the current task. You never load all skills at once. If two skills' triggers conflict, follow the task's Scope/Objective and the project's stated design direction — do not blend contradictory styles.

| Skill | Load it WHEN… | What it gives you |
|---|---|---|
| `frontend-design` | Always, as your baseline (any UI work) | Core visual-design direction: aesthetic choices, typography, avoiding templated defaults |
| `frontend-ui-engineering` | You are building a component/page that must be production-ready, accessible (WCAG), responsive | Build standards: accessibility, responsiveness, clean component architecture |
| `design-taste-frontend` | You are making layout/UX decisions from scratch | Senior UX/UI framework: metric-based rules, component discipline, balanced design |
| `high-end-visual-design` | The project wants a premium/expensive feel (or no explicit aesthetic is stated) | Agency-grade polish: exact fonts, spacing, shadows, card structure, animation cost |
| `ui-ux-pro-max` | You need a quick reference for a specific UI element (styles, palettes, font pairings, chart types) | Reference library: 50+ styles, 161 palettes, 57 font pairings, 99 UX guidelines |
| `impeccable` | You are being asked to redesign/refine/critique an existing interface, not build fresh | UI audit & polish workflow: hierarchy, cognitive load, state, empty states |
| `apple-design` | You are building gesture-driven UI, sheets, spring animations, or translucent materials | Apple-style physical motion & material design for the web |
| `emil-design-eng` | You are polishing micro-interactions / the "invisible details" of a UI | High-craft UI polish philosophy |
| `gpt-taste` | You need advanced GSAP motion + strong editorial layout decisions | Elite motion + layout taste (GSAP-based) |
| `minimalist-ui` | The project's stated design direction is minimal/editorial (warm mono palette) | A cohesive minimalist aesthetic |
| `industrial-brutalist-ui` | The project's stated design direction is brutalist/industrial/technical | A raw mechanical aesthetic (rigid grids, stark type) |
| `stitch-design-taste` | You are establishing or enforcing a DESIGN.md / design-system file for the project | Generates a DESIGN.md enforcing premium, anti-generic standards |
| `theme-factory` | You are applying a consistent theme across multiple artifacts (docs, HTML, slides) | Reusable theme application (10 presets + on-the-fly) |
| `tailwind-design-system` | The project uses Tailwind CSS and you need design tokens/component library conventions | Tailwind v4 tokens, component libs, responsive patterns |
| `web-design-guidelines` | You must self-review your UI against interface guidelines / accessibility | Compliance checklist: accessibility, UX, motion |
| `redesign-existing-projects` | You are working in an existing app/site that looks generic and must be upgraded | Upgrade workflow: audit current design, apply premium standards without breaking |
| `pick-ui-library` | You need to choose a library/component for a specific need (charts, OTP, drag-drop, toasts…) | Curated list of the right lib per task |
| `imagegen-frontend-web` | You need design-reference images or section concepts to guide your build | Generates section-by-section visual direction references |
| `imagegen-frontend-mobile` | The target is a mobile app (iOS/Android) and you need screen concepts | Mobile-native screen concepts & flows |
| `web-artifacts-builder` | You are building a rich HTML/React artifact (state management, routing, shadcn/ui) | Component/generation suite for elaborate artifacts |
| `animate` | You need to decide whether/how to animate something, from scratch | Animation decision framework + implementation |
| `framer-motion` | The project uses Framer Motion (React) | Framer Motion patterns (gestures, transitions, orchestration) |
| `gsap-core` / `gsap-react` | The project uses GSAP (or you need high-performance web animation) | GSAP API core / React integration |
| `gsap-scrolltrigger` | You need scroll-based animation (parallax, pinned sections) | ScrollTrigger patterns |
| `review-animations` | You are reviewing motion you already wrote against a high craft bar | Animation critique rubric |
