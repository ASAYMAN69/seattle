# Project — Seattle Transit Equity Index (DataNova 2026)

## What we are building
An interactive, data-driven **Transit Equity Index for Seattle** that reveals which
communities are underserved by transit relative to their need, quantifies the gap,
and recommends concrete service changes — delivered as a working web demo
(TypeScript SPA over a FastAPI backend) plus a submission deck.

## For whom
- Judges / demo viewers (90-second clarity, map, wow moment, story)
- Transit planners / advocates (rigor, filters, methodology, exportable numbers)
- Residents / civic users (their neighborhood's grade + recommendations)

## Why
DataNova 2026 Global Data-thon — Track: Operations Research & Decision
Intelligence / Data Science & Advanced Analytics. Deadline: **Nov 11, 2026,
04:00 GMT+6** (Devpost). Judged on: Technical Implementation 25%, Innovation 20%,
Data & Analytical Rigor 15%, Impact & Feasibility 15%, Problem Relevance 15%,
Presentation & Documentation 10%.

## Differentiation
- Neighborhood "Equity Report Card" with letter grades (A–F) per dimension.
- Access − Need gap score highlighting "high need, low access" corridors.
- What-if service-change explorer (precomputed sensitivity, lightweight at runtime).
- Real narrative anchor (e.g., a low-income block group with a long commute).
- Decision-intelligence output: concrete, quantified recommendations.

## Hard principles
Real data only · no mock/synthetic · free tier only · no ML model serving.
