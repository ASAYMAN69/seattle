# SKILLS.md — Patrick (Security Expert) skill map

> **How to use this file.** At the start of every task, read this list. Load a skill **only if its trigger condition is true** for the current task. You never load all skills at once.

| Skill | Load it WHEN… | What it gives you |
|---|---|---|
| `security-audit` | You are running a full or focused vulnerability review of the codebase/APIs/services | Structured security audit workflow (OWASP-minded, report artifacts) |
| `security-and-hardening` | You are reviewing a specific input handler, auth flow, storage path, or external integration | Hardening patterns for the attack surface at hand |
| `doubt-driven-development` | A security claim or fix is about to stand and needs adversarial re-review | Fresh-context adversarial verification before accepting |
| `code-review-and-quality` | You need to assess code quality / posture alongside security findings | Multi-axis code assessment |
